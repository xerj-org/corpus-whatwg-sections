  <div algorithm>
  <p>The <code>center</code> element, and the <code>div</code> element when it has an <code
  data-x="attr-div-align">align</code> attribute whose value is an <span>ASCII
  case-insensitive</span> match for either the string "<code data-x="">center</code>" or the string
  "<code data-x="">middle</code>", are <span>expected</span> to center text within themselves, as
  if they had their <span>'text-align'</span> property set to 'center' in a <span
  data-x="presentational hints">presentational hint</span>, and to <span>align descendants</span>
  to the center.</p>
  </div>

  <div algorithm>
  <p>The <code>div</code> element, when it has an <code data-x="attr-div-align">align</code>
  attribute whose value is an <span>ASCII case-insensitive</span> match for the string "<code
  data-x="">left</code>", is <span>expected</span> to left-align text within itself, as if it had
  its <span>'text-align'</span> property set to 'left' in a <span data-x="presentational
  hints">presentational hint</span>, and to <span>align descendants</span> to the left.</p>
  </div>

  <div algorithm>
  <p>The <code>div</code> element, when it has an <code data-x="attr-div-align">align</code>
  attribute whose value is an <span>ASCII case-insensitive</span> match for the string "<code
  data-x="">right</code>", is <span>expected</span> to right-align text within itself, as if it had
  its <span>'text-align'</span> property set to 'right' in a <span data-x="presentational
  hints">presentational hint</span>, and to <span>align descendants</span> to the right.</p>
  </div>

  <div algorithm>
  <p>The <code>div</code> element, when it has an <code data-x="attr-div-align">align</code>
  attribute whose value is an <span>ASCII case-insensitive</span> match for the string "<code
  data-x="">justify</code>", is <span>expected</span> to full-justify text within itself, as if it
  had its <span>'text-align'</span> property set to 'justify' in a <span data-x="presentational
  hints">presentational hint</span>, and to <span>align descendants</span> to the left.</p>
  </div>
